# Atlas Markdown export acceptance checklist

Atlas is a fictional tool costing $30/month with Markdown export. Beacon costs $20/month without export. Export is required; the unresolved question is whether Atlas exports everything we need.

These are proposed trial criteria, not verified Atlas capabilities. Use a small sample of representative content, keeping a source copy for comparison. Record pass/fail and evidence for each check; leave checks unchecked until tested.

- [ ] **Obtain usable Markdown.** Export a sample document and open the resulting Markdown in a plain-text editor. Pass if the file opens and its content is readable without Atlas.
- [ ] **Preserve all text.** Include a unique title, opening sentence, several paragraphs, and a closing marker in the sample. Compare source and export. Pass if every text block appears exactly once, in the original order, with no truncation.
- [ ] **Preserve required formatting.** Include the formatting we use, such as headings, lists, emphasis, and code blocks. Render the export in an independent Markdown viewer. Pass if each required element retains its meaning and structure; record any unsupported element as a gap.
- [ ] **Keep required links and assets usable.** Include representative links and any images or attachments we need to retain. Open each from the exported copy outside Atlas. Pass if required destinations resolve and required assets remain accessible without Atlas; document any missing or Atlas-dependent items.
- [ ] **Cover the full selected scope.** Make an inventory of the documents and associated content chosen for the trial, then export them using the available workflow. Pass if every required item can be matched to an exported counterpart, with no omissions or unexplained duplicates.
- [ ] **Support continued work outside Atlas.** Move the exported files and assets into a separate folder, open them in an independent Markdown editor, make a small edit, save, and reopen. Pass if the edit persists and the required content remains usable without returning to Atlas.

Accept the trial only when all six checks pass for the agreed sample. Record failures as export-coverage gaps to resolve before relying on Atlas; this checklist does not establish a free trial or any unmentioned feature.
